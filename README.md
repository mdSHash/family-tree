# شجرة العيلة

تطبيق ويب (PWA) لتسجيل العيلة كلها، من الأجداد للأحفاد. بتدخل الشخص وصلته بغيره (أب، أم، ابن، أخ، زوج…) والشجرة بترسم نفسها. بيشتغل على الموبايل زي التطبيق وعلى الكمبيوتر.

## المميزات
- ترتيب تلقائي للشجرة، مع الأزواج جنب بعض والولاد تحت أبوهم وأمهم
- صورة وسنة ميلاد ووفاة وملاحظات لكل شخص
- حاسبة صلة القرابة (عم، خال، ابن عمة، حما، مرات الابن…)
- بحث، عرض فرع شخص واحد، تكبير وتصغير ولمس
- تصدير PNG و PDF
- مشاركة بلينكين: لينك مشاهدة ولينك تعديل
- بيفتح من غير نت آخر نسخة، والتعديلات اللي تتعمل أوفلاين بتتحفظ أول ما النت يرجع
- نسخة احتياطية JSON

## التشغيل
```bash
npm install
cp .env.example .env   # حط بيانات Supabase
npm run dev
```

## قاعدة البيانات
شغّل `supabase/schema.sql` في SQL Editor على مشروع Supabase. الجداول مقفولة بـ RLS، وكل الوصول بيعدّي من functions بتتحقق من كود الشجرة.

## النشر
مربوط بـ Vercel. محتاج المتغيرات `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
